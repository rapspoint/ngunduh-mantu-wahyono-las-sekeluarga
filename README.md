# Undangan Digital Ngunduh Mantu

## Cara Deploy ke GitHub Pages:
1. Buat repository baru di GitHub (misal: `undangan-ngunduh-mantu`).
2. Upload semua file dalam folder ini (`index.html` dan `music.mp3`) ke repository tersebut.
3. Buka tab **Settings** di repository GitHub Anda.
4. Pergi ke bagian **Pages** (di menu sebelah kiri).
5. Pada bagian **Build and deployment**, pastikan Source adalah "Deploy from a branch".
6. Di bagian **Branch**, pilih branch `main` (atau `master`), lalu klik **Save**.
7. Tunggu beberapa menit, GitHub akan memberikan link website undangan Anda (contoh: `https://username.github.io/undangan-ngunduh-mantu`).

## Cara Mengganti Musik:
1. Siapkan file musik (format `.mp3`) yang ingin Anda gunakan.
2. Ubah nama file musik Anda menjadi **`music.mp3`**.
3. Timpa/Ganti (replace) file `music.mp3` bawaan dari folder ini dengan file musik Anda sendiri.

## Cara Sebar Undangan dengan Nama Tamu:
Tambahkan `?to=Nama+Tamu` di akhir link undangan Anda.
Ganti spasi dengan tanda plus (`+`).

Contoh:
`https://username.github.io/undangan-ngunduh-mantu/?to=Bapak+Budi+dan+Keluarga`
